NexCraft - Minecraft Java Edition server and mod manager for Windows

How to run
  1. Extract this whole folder anywhere you can write to (not Program Files).
  2. Run NexCraft.exe.

Your data (servers, settings, logs, backups) is kept in the "data" folder
next to NexCraft.exe. To move NexCraft, move the whole folder.

NexCraft does not need Java to start. It finds or downloads the right Java
for each server when you create one.
